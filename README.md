# Tunnel Map

משחק דו ממדי שבנינו ביוניטי במסגרת מטלה 2. השחקן זז במנהרות חשוכות עם פנס, ובפינה הימנית העליונה יש מפה קטנה שמראה איפה הוא נמצא.

## איך משחקים

זזים עם מקשי החיצים. המקש M מציג ומסתיר את המפה הקטנה.

## שאלה 2

### א

השדה Size של מצלמה אורתוגרפית קובע חצי מהגובה של העולם שהמצלמה מראה. הגובה הזה נשאר קבוע, והרוחב מחושב לפי היחס בין הרוחב לגובה של המסך.

כשמסובבים את הטלפון למצב אנכי ה Size לא משתנה, אז המצלמה מראה את אותו גובה של עולם, רק שעכשיו הוא נפרס על הצד הארוך של המסך. לכן כל יחידה בעולם מקבלת יותר פיקסלים והעצמים נראים גדולים יותר, ובצדדים רואים פחות מהעולם.

### ב

כתבנו את הסקריפט [OrientationCameraSize](Assets/Scripts/Camera/OrientationCameraSize.cs) ושמנו אותו על המצלמה הראשית. הוא משנה רק את orthographicSize ולא נוגע באף עצם אחר.

הגודל שמוגדר ב Inspector הוא הגודל למצב אופקי. כשהמסך עובר למצב אנכי, הסקריפט מכפיל אותו ביחס בין הצד הארוך לצד הקצר של המסך, וככה העצמים נשארים באותו גודל.
